# راهنمای جامع استقرار پروژه «جهش کار» روی هاست اشتراکی (cPanel / DirectAdmin)

این سند راهنمای گام‌به‌گام و ساده برای استقرار پروژه سامانه فروش دوره **«جهش کار»** بر روی هاست‌های اشتراکی سی‌پنل (دارای قابلیت Setup Python App) یا هاست‌های دایرکت‌ادمین است.

---

## روش اول: استقرار یکپارچه (توصیه شده - All-in-One)
در این روش، فایل‌های کامپایل‌شده فرانت‌اند React مستقیماً توسط جنگو سرو می‌شوند و شما تنها **یک دامین** (مثلاً `yoursite.ir`) نیاز دارید و با هیچ ارور CORS یا تنظیمات پیچیده روبرو نمی‌شوید.

### گام ۱: ساخت فایل‌های بیلد فرانت‌اند در سیستم خودتان
قبل از آپلود، در پوشه پروژه فایل `build_for_hosting.bat` را اجرا کنید (یا دستورات زیر را دستی بزنید):
```bash
cd frontend
npm run build
cd ../backend
python manage.py collectstatic --noinput
```
این کار پوشه `frontend/dist` و فایل‌های استاتیک در `backend/staticfiles` را آماده می‌کند.

---

### گام ۲: ایجاد نرم‌افزار پایتون در سی‌پنل (Setup Python App)
1. وارد کنترل‌پنل **cPanel** هاست خود شوید.
2. از بخش **Software**، بر روی گزینه **Setup Python App** کلیک کنید.
3. دکمه **Create Application** را بزنید:
   - **Python Version**: نسخه `3.10` یا `3.11` را انتخاب کنید.
   - **Application root**: نام پوشه‌ای که پروژه در آن قرار می‌گیرد را وارد کنید (مثلاً `jaheshkar` یا `backend`).
   - **Application URL**: دامنه یا ساب‌دامینی که می‌خواهید سایت روی آن باز شود را انتخاب کنید.
   - **Application startup file**: بنویسید: `passenger_wsgi.py`
   - **Application Entry point**: بنویسید: `application`
4. دکمه **Create** را بزنید تا برنامه ایجاد شود.

---

### گام ۳: آپلود فایل‌ها به هاست
1. تمام فایل‌ها و پوشه‌های پروژه (شامل `backend` و `frontend`) را در قالب یک فایل ZIP فشرده کنید (پوشه‌های `venv` و `node_modules` را فشرده **نکنید**).
2. وارد بخش **File Manager** در سی‌پنل شوید.
3. به پوشه‌ای که در گام قبل برای Application Root تعیین کردید بروید و فایل ZIP را آپلود و **Extract** کنید.
4. مطمئن شوید فایل `passenger_wsgi.py` در ریشه همان مسیر قرار دارد.

---

### گام ۴: نصب پکیج‌های پایتون (Dependencies)
1. در صفحه **Setup Python App** سی‌پنل، در بالای صفحه دستور فعال‌سازی محیط مجازی نوشته شده است (مثلاً `source /home/username/virtualenv/.../bin/activate`).
2. از سی‌پنل وارد ابزار **Terminal** شوید و آن خط دستور را Paste و اجرا کنید تا محیط مجازی فعال شود.
3. دستور زیر را برای نصب کتابخانه‌ها اجرا کنید:
   ```bash
   pip install -r requirements.txt
   ```

---

### گام ۵: اعمال دیتابیس و داده‌های اولیه
در همان ترمینال، دستورات زیر را به ترتیب اجرا نمایید:
```bash
python manage.py migrate
python manage.py seed_data
```
با این دستورات:
- جداول دوره‌ها، جلسات، کاربران و سفارشات در دیتابیس ساخته می‌شود.
- کاربر مدیر با نام کاربری `admin` و رمز `admin123456` ساخته می‌شود.
- دوره‌ها و سرفصل‌های اولیه نمونه ایجاد می‌گردد.

---

### گام ۶: ری‌استارت برنامه در سی‌پنل
در بخش **Setup Python App**، روی دکمه **Restart** کلیک کنید.
حالا آدرس سایت خود را در مرورگر باز کنید؛ پروژه زیبای جهش کار در دسترس شماست!
برای ورود به پنل ادمین جهت آپلود ویدیوها، به آدرس `yoursite.ir/admin/` بروید.

---

## اتصال به پایگاه داده MySQL (در صورت نیاز)
پروژه به‌صورت پیش‌فرض از SQLite بدون دردسر استفاده می‌کند که روی اکثر هاست‌های اشتراکی عالی و پرسرعت کار می‌کند.
اگر کارفرما اصرار به دیتابیس MySQL دارد:
1. در سی‌پنل از بخش **MySQL Databases** یک دیتابیس و کاربر بسازید و دسترسی کامل دهید.
2. در پوشه `backend` یک فایل به نام `.env` بسازید و اطلاعات زیر را وارد کنید:
   ```env
   DB_ENGINE=mysql
   DB_NAME=نام_دیتابیس
   DB_USER=نام_کاربر
   DB_PASSWORD=رمز_دیتابیس
   DB_HOST=localhost
   DB_PORT=3306
   ```
3. در ترمینال هاست پکیج درایور را نصب کنید:
   ```bash
   pip install pymysql
   ```
4. دستور `python manage.py migrate` را اجرا کنید.

---

## نحوه آپلود و مدیریت ویدیوها توسط ادمین در پنل
1. وارد پنل مدیریت جنگو در آدرس `https://yoursite.ir/admin/` شوید.
2. نام کاربری و رمز عبور را وارد کنید.
3. در بخش **دوره‌های آموزشی**:
   - می‌توانید دوره جدید بسازید.
   - کاور دوره را انتخاب یا آپلود کنید.
   - برای ویدیوی معرفی (تیزر): هم می‌توانید فایل mp4 ویدیوی معرفی را **مستقیم آپلود** کنید و هم می‌توانید **لینک مستقیم** از هاست دانلود یا آروان‌کلاد قرار دهید.
   - در همان صفحه دوره، در بخش **فصل‌های دوره** و **جلسات آموزشی این دوره**، مستقیماً جلسات را اضافه کنید، ترتیب آن‌ها را مشخص کنید، تیک «پیش‌نمایش رایگان» بزنید و ویدیوهای هر قسمت را آپلود یا لینک کنید.
   - فایل‌های تمرینی و کدهای پروژه را نیز می‌توانید به هر جلسه پیوست کنید.

---

## سناریوهای داینامیک پشتیبانی شده:
- **دوره تک‌بخشی بدون فصل**: می‌توانید بدون تعریف سرفصل، ویدیوها را مستقیماً زیرمجموعه دوره تعریف کنید.
- **دوره پیشرفته با فصل‌بندی**: می‌توانید فصل ۱، فصل ۲ و... تعریف کرده و برای هر فصل بینهایت جلسه بگذارید.
- **جلسات رایگان و پولی**: هر جلسه‌ای که تیک «پیش‌نمایش رایگان» داشته باشد بدون پرداخت برای همه قابل تماشا است و سایر جلسات بلافاصله پس از ثبت‌نام/خرید بازگشایی می‌شوند.
- **روش‌های ورود**: کاربر می‌تواند با شماره موبایل و کد پیامکی وارد شود یا با نام کاربری و پسوورد.
