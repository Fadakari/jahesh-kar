# سامانه آموزشی و فروش دوره «جهش کار» (JaheshKar)

پلتفرم مدرن، سریع و ساده جهت فروش و تماشای دوره‌های آموزشی آنلاین، طراحی شده برای اجرای محلی سریع و استقرار روان بر روی **هاست اشتراکی (cPanel / DirectAdmin)**.

---

## ویژگی‌های اصلی سیستم

### ۱. معماری و بک‌اند (Python & Django + DRF)
- **پنل ادمین کاملاً فارسی و شخصی‌سازی شده:** امکان تعریف آسان دوره‌ها، سرفصل‌ها و جلسات آموزشی با قابلیت آپلود مستقیم فایل‌های ویدیویی (MP4) یا قرار دادن لینک مستقیم هاست دانلود/سرویس CDN (مانند آروان‌کلاد).
- **پشتیبانی از سناریوهای داینامیک:**
  - دوره‌های تک‌مرحله‌ای (فهرست ساده ویدیوها) یا چند فصلی و طبقه‌بندی شده.
  - ویدیوی معرفی و تیزر دوره (آپلود مستقیم یا لینک بیرونی).
  - پیش‌نمایش رایگان جلسات دلخواه (Sample/Free Preview) بدون نیاز به خرید.
  - پیوست فایل‌های دانلودی، سورس‌کد و اسلایدهای پروژه در هر جلسه.
- **سیستم احراز هویت دوگانه (کاملاً اختیاری توسط کاربر):**
  - **ورود با پیامک (OTP):** کاربر شماره موبایل خود را وارد کرده و کد تایید ۵ رقمی را وارد می‌کند.
  - **ورود با نام کاربری و کلمه عبور:** ثبت‌نام استاندارد و ورود سنتی.
- **مدیریت سفارشات و ثبت‌نام (Checkout & Enrollment):** شبیه‌سازی درگاه پرداخت آنلاین با تخصیص کد رهگیری و بازگشایی آنی دسترسی دانشجو به ویدیوهای قفل شده.

### ۲. فرانت‌اند و رابط کاربری (React + Vite + Tailwind CSS)
- **طراحی زیبا، سریع و استاندارد فارسی (RTL):** با تایپوگرافی چشم‌نواز فونت وزیرمتن (Vazirmatn) و آیکون‌های مدرن Lucide.
- **صفحات کامل:**
  - **صفحه اصلی (Home):** هدر جذاب، جستجوی زنده، دسته‌بندی‌ها، دوره‌های برگزیده، مزایای رقابتی و فوتر حرفه‌ای.
  - **بانک دوره‌ها (Catalog):** فیلتر بر اساس دسته‌بندی، سطح آموزشی (مقدماتی، متوسط، پیشرفته)، نوع دوره (رایگان/پولی) و کلمات کلیدی.
  - **صفحه معرفی دوره (Course Detail):** پخش‌کننده تیزر معرفی، سرفصل‌ها و آکاردئون جلسات با نشانگرهای قفل/رایگان، بیوگرافی مدرس، سرفصل‌های اکتسابی و کارت خرید شناور.
  - **استودیو تماشای دوره (Course Player / LMS):** محیط یادگیری تمرکزیافته (Distraction-free) با پلیر ویدیو، دکمه‌های جلسه قبل/بعد، دانلود سورس‌کد جلسه و پلی‌لیست تعاملی با تغییر لحظه‌ای ویدیو بدون رفرش صفحه.
  - **ورود و ثبت‌نام (Login / Register):** تب‌های تعاملی برای انتخاب بین ورود پیامکی، ورود رمز عبور و ثبت‌نام جدید.
  - **داشبورد دانشجو (Dashboard):** مشاهده دوره‌های ثبت‌نام شده، تاریخچه سفارشات و کدهای رهگیری، و ویرایش پروفایل.

## نحوه اجرای سریع در سیستم شما (Local Run)

### روش اول: اجرای تک‌کلیک (ویندوز)
کافیست فایل **`run_all.bat`** را اجرا کنید تا هر دو سرور بک‌اند و فرانت‌اند به طور خودکار باز شوند.

یا می‌توانید جداگانه اجرا کنید:
- **`run_backend.bat`**: اجرای سرور جنگو روی پورت ۸۰۰۰
- **`run_frontend.bat`**: اجرای سرور ری‌اکت روی پورت ۵۱۷۳

---

### روش دوم: اجرای دستی از طریق ترمینال

#### اجرای بک‌اند (Django):
```bash
cd backend
..\venv\Scripts\python manage.py runserver 127.0.0.1:8000
```
- آدرس API: `http://127.0.0.1:8000/api/`
- آدرس پنل ادمین: `http://127.0.0.1:8000/admin/`

#### اجرای فرانت‌اند (React):
```bash
cd frontend
npm run dev
```
- آدرس سایت: `http://localhost:5173/`

## استقرار روی هاست اشتراکی (cPanel / DirectAdmin)

برای راهنمای جامع و تصویری، فایل **`deploy/cpanel_guide.md`** را مطالعه فرمایید.
به طور خلاصه:
1. فایل `build_for_hosting.bat` را اجرا کنید تا فرانت‌اند کامپایل و فایل‌های استاتیک جمع‌آوری شوند.
2. در سی‌پنل از بخش **Setup Python App** یک برنامه پایتون با مسیر `backend` و فایل `passenger_wsgi.py` بسازید.
3. فایل‌ها را آپلود کرده و دستورات `pip install -r requirements.txt` و `python manage.py migrate` را اجرا کنید.
4. پروژه به صورت یکپارچه با دامنه شما بالا می‌آید و بدون نیاز به هاست مجزا آماده بهره‌برداری است.
